# Changelog

모든 주요 변경 사항은 이 파일에 기록됩니다. `gpa-tapfree` (Android) 의 버전은 `gpi-tapfree` (iOS) 와 별개입니다.

## [2.0.4] - 2026-10-06 (Hotfix)

> 2.0.3 의 hotfix 릴리스.

### 수정

- **Zone 을 벗어났다가 곧바로 다시 들어올 때 Edge 접속이 반복해서 끊기던 문제를 수정했다.**  
이전에는 접속이 끊기고 `onStartedTracking` / `onStoppedTracking` 이 계속 반복되는 경우가 있어 긴급 수정

### 호환성

- 공개 API 는 변경되지 않았다.

## [2.0.3] - 2026-06-12

### 추가

- **`TapfreePlatform.start()` 에 `ddnsDomain` 파라미터 추가** — DDNS 도메인이 사이트마다 다를 수 있는 환경에 대비한다. Edge 접속 호스트에 사용할 DDNS 도메인을 지정할 수 있다. 기존 호출부는 그대로 동작한다.

### 변경

- **`gp-location-filter` 의존성이 외부 사용 앱에 전이 노출되지 않도록 변경**했다.

## [2.0.2] - 2026-06-09

### 수정

- **UWB MAC 주소 처리 수정**: 안드로이드 측 UWB address 를 little-endian → big-endian 으로 변환하도록 수정.

## [2.0.1] - 2026-06-09

### 변경

- **외부 사용자가 내부 저장소 접근 없이 본 라이브러리를 사용할 수 있도록** 필요한 의존 라이브러리를 함께 제공한다.

## [2.0.0] - 2026-06-05

### 추가

- **DL-TDoA 운영 통합**: 표준 `android.ranging` API 경로로 UWB 측위를 수행한다.
- **백그라운드 측위 지원**: 백그라운드 상태에서도 측위를 유지할 수 있다.

### 변경

- 외부 사용자의 디버깅 편의를 위해 release 빌드의 난독화를 제거했다.
